[h1]涡轮增压扩展[/h1]

让[b]涡轮增压器[/b]（基础 / 高级 / 超科技）可以对养殖相关目标使用，[b]推进一天[/b]。

[h2]能对什么用[/h2]
[list]
[*][b]循环水养殖系统[/b]：整缸鱼过一天（生长、摄食、繁殖、死亡判定）
[*][b]养殖笼[/b]：笼里[b]每一只[/b]活着的动物各过一天
[*][b]单只动物[/b]（老鼠等）：这一只过一天
[/list]

[h2]规则说明（都是有意为之）[/h2]
[list]
[*][b]消耗照旧[/b]：基础款用完即毁；高级 / 超科技扣充能
[*][b]空笼子不可选[/b]：笼里没有活体动物时涡轮指不上去，避免浪费
[*][b]死动物不可选[/b]：笼内的死个体也会自动跳过
[*][b]笼子耐久[/b]：对笼子用涡轮会照原版扣一次耐久，和正常过夜一致
[*][b]环境规则不变[/b]：断电的养殖系统依然让鱼掉健康，缺水缺料依然按原版处理
[*][b]一天就是一天[/b]：不会跳生长阶段；连用多个涡轮 = 推进多天
[/list]

[h2]兼容与安全[/h2]
[list]
[*]不需要任何能力声明，启用时不会弹确认框
[*][b]不写入存档数据[/b]，卸载不会损坏存档
[*]不动养鱼 / 养鼠的成长逻辑，只改「涡轮能指向谁」和「对笼子用涡轮时推进笼内动物」
[*]与本模组思路相同的涡轮类模组可能重复推进，只装一个
[/list]

[h2]安装[/h2]
订阅后，在游戏内「模组」菜单启用，然后[b]重启游戏[/b]。
