[h1]Better Turbo Booster[/h1]

Makes the [b]Turbo Booster[/b] (basic / advanced / hypertech) usable on husbandry targets, advancing them by [b]one day[/b].

[h2]What you can boost[/h2]
[list]
[*][b]Recirculating aquaculture system[/b]: the whole tank ticks one day (growth, feeding, breeding, death checks)
[*][b]Animal cage[/b]: every live animal inside advances one day
[*][b]A single animal[/b] (rat, etc.): that animal advances one day
[/list]

[h2]Rules (all intentional)[/h2]
[list]
[*][b]Costs are unchanged[/b]: the basic booster is consumed; advanced / hypertech consume charge
[*][b]Empty cages are not selectable[/b], so you never waste a booster on nothing
[*][b]Dead animals are not selectable[/b] and are skipped inside cages
[*][b]Cage durability[/b] still decays once per boost, exactly like a normal night
[*][b]Environment rules still apply[/b]: an unpowered RAS still hurts fish, missing water/food still kills
[*][b]One day is one day[/b]: no stage skipping; using several boosters stacks multiple days
[/list]

[h2]Compatibility[/h2]
[list]
[*]Declares no capabilities, so enabling it shows no confirmation prompt
[*][b]Writes nothing to save files[/b]; uninstalling cannot corrupt a save
[*]Touches only "what a booster may target" and "advance caged animals when a booster is used"
[*]Other turbo mods that patch the same checks may double-advance; install only one
[/list]

[h2]Install[/h2]
Subscribe, enable it in the in-game Mods menu, then [b]restart the game[/b].
