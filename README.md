# 涡轮增压扩展

《深空当铺：可能是偷的》模组：让**涡轮增压器**（基础 / 高级 / 超科技）可以对养殖相关目标使用，**推进一天**。

## 能对什么用

| 目标 | 效果 |
|---|---|
| 循环水养殖系统 | 整缸鱼过一天：生长、摄食、繁殖、死亡判定 |
| 养殖笼 | 笼里**每一只**活着的动物各过一天 |
| 单只动物（老鼠等） | 这一只过一天 |

## 规则说明

- **消耗照旧**：基础款用完即毁，高级 / 超科技扣充能
- **空笼子不可选**：笼里没有活体动物时涡轮指不上去，不会白烧一个
- **死动物不考虑**：不可选中，笼内的死个体也会自动跳过
- **笼子耐久**：对笼子用涡轮会照原版扣一次耐久，和正常过夜一致
- **环境规则不变**：断电的养殖系统依然让鱼掉健康，缺水缺料依然按原版处理
- **一天就是一天**：不跳生长阶段；连用多个涡轮 = 推进多天

## 安装

**创意工坊**：订阅 → 游戏内「模组」菜单启用 → 重启游戏。

**手动**：下载 Release 里的 zip，解压到 `<游戏目录>\Mods\ras_turbo_boost\`（该目录下应直接是 `manifest.xml` 和 `ras_turbo_boost.dll`），启用后重启。

## 常见问题

**会影响存档吗？**
不会。模组不写入任何存档数据，卸载后存档完好。

**和其他涡轮类模组冲突吗？**
如果对方也改了涡轮的可选中判定，可能重复推进；只装一个。

**需要额外的前置模组吗？**
不需要，也没有任何权限声明，启用时不会弹确认框。
